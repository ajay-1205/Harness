# Haiku skill

Write a traditional 5-7-5 syllable haiku on the requested topic.
Rules:
- No title, no explanation -- output ONLY the three lines.
- Prefer concrete imagery over abstract statements.
- Count syllables carefully; a haiku with wrong syllable counts is a failed haiku.
